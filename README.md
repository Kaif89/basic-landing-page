# Institute of Digital Risk (IDR) - Landing Page

Welcome to the **Institute of Digital Risk (IDR)** landing page project. 

This repository contains the front-end code for a modern, responsive, and dynamic landing page built for IDR—an industry-led training and deployment institute explicitly built for the challenges of today's digital, cyber, and technology risk landscapes.

## 🚀 Features

- **Modern UI/UX:** A stunning dark-mode-first fintech/education aesthetic with vibrant orange accents (#FF5A00).
- **Responsive Layout:** fully optimized for desktops, tablets, and mobile devices.
- **Micro-interactions:** Scroll reveal, floating icon animations, and an interactive pipeline tracker using pure CSS/JS.
- **Dynamic Theme Toggling:** Users can switch between dark and light modes seamlessly.
- **Semantic Structure:** Clean HTML5 layered with custom CSS and lightweight Vanilla JavaScript.

## 🛠️ Built With

- **HTML5:** For the structural foundation.
- **CSS3:** For responsive design, CSS Grid/Flexbox layouts, and custom animations (no external frameworks used, ensuring complete control).
- **Vanilla JavaScript:** For interactive elements such as the mobile menu, scroll reveal animations, sticky navbar, and the interactive pipeline tracker.
- **Phosphor Icons:** For clean, scalable iconography.

## 🚀 Getting Started

To view the landing page locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Kaif89/basic-landing-page.git
   ```
2. Open `index.html` in your favorite web browser.

Alternatively, you can run a local development server using tools like VS Code Live Server or Python's built-in HTTP server:
```bash
python3 -m http.server 8000
```
Then, navigate to `http://localhost:8000` in your browser.

The aesthetic combines an isometric split-cube icon symbolizing a secure, resilient core with a visually stunning user experience.
